# Conceitos de Cloud Computing

Computação em nuvem é o modelo de entrega de recursos de TI, como servidores, armazenamento, bancos de dados, redes, software e inteligência artificial, sob demanda via internet, com pagamento conforme o uso. Em vez de manter infraestrutura física própria, organizações e desenvolvedores acessam esses recursos de forma elástica, escalável e gerenciada por provedores especializados.

Os modelos de serviço mais comuns são:
- **IaaS** (Infrastructure as a Service): infraestrutura virtualizada (servidores, redes, armazenamento).
- **PaaS** (Platform as a Service): plataforma gerenciada para desenvolvimento e deploy de aplicações.
- **FaaS/Serverless**: execução de código orientada a eventos sem gerenciamento de servidores.

Entre os principais provedores estão Amazon Web Services (AWS), Google Cloud Platform (GCP) e Microsoft Azure.
