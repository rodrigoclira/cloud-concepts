## Lambda

O **AWS Lambda** é o serviço de computação serverless da AWS. Ele permite executar código em resposta a eventos — como requisições HTTP, modificações em buckets S3, mensagens em filas SQS ou triggers de banco de dados — sem a necessidade de provisionar ou gerenciar servidores.

O modelo de cobrança é baseado no número de invocações e no tempo de execução (em incrementos de 1 ms), tornando-o econômico para cargas de trabalho intermitentes. O Lambda suporta múltiplos runtimes, incluindo Python, Node.js, Java e Go, e escala automaticamente de forma concorrente conforme a demanda.
